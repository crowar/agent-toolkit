# Инструкции для агентов

Этот репозиторий — каталог переносимых навыков (skills) для AI-агентов.
Здесь нет приложения, сборки и CI: артефакты — это Markdown-инструкции и
вспомогательные скрипты. Подробности и каталог навыков — в [README.md](./README.md).

## Структура

- `skills/<skill-name>/SKILL.md` — главный файл навыка (frontmatter + инструкции).
- `skills/<skill-name>/scripts/` — вспомогательные скрипты навыка.
- `skills/<skill-name>/references/` — дополнительные документы, на которые
  ссылается `SKILL.md` относительными ссылками (`./references/...`).
- `.agents/`, `.claude/`, `.codemie/`, `skills-lock.json` — локально установленные
  навыки и настройки агентов; они в `.gitignore` — не редактируйте и не коммитьте их.

## Конвенции навыков

- Каждый `SKILL.md` начинается с YAML frontmatter с полями `name` и `description`.
- `name` обязан совпадать с именем папки навыка (kebab-case).
- `description` пишется по шаблону «что делает + когда использовать» и содержит
  триггерные фразы; значения с двоеточиями берите в кавычки.
- Язык инструкций — русский или английский, следуйте стилю существующих навыков;
  README ведётся на русском.
- Навык должен быть автономным: все ссылки внутри навыка — относительные,
  без путей на другие навыки или внешние локальные файлы.
- При добавлении/переименовании/удалении навыка обновите каталог в
  [README.md](./README.md): название, краткое описание и команду установки
  `npx skills add https://github.com/crowar/agent-toolkit --skill <name>`.

## Скрипты

- Python 3, только стандартная библиотека — без сторонних зависимостей,
  `requirements.txt` и виртуальных окружений.
- Секреты только через `.env` в корне целевого репозитория с уникальным префиксом
  навыка (пример: `CIFIX_*` в `fix-ci-failures`). Скрипты не печатают и не
  коммитят токены; `.env` добавляется в `.gitignore`.
- После правок проверяйте синтаксис: `python3 -m py_compile skills/<name>/scripts/*.py`.

## Рабочий процесс

- Не делайте `git commit`/`git push` без явной просьбы пользователя.
- Коммиты — в стиле Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`),
  как в истории репозитория.
- Не добавляйте бинарные артефакты, сгенерированный вывод (`output/`, `preview/`)
  и установленные навыки в git.
