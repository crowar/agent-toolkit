# Прежняя визуальная система: light-business

Используй только при явном выборе `theme: "light-business"` или для старого
оглавления без поля `theme`. Новые презентации по умолчанию используют Euclidean;
см. [design.md](design.md).

| Параметр | Значение |
|---|---|
| Формат | 16:9, 13.333 × 7.5 дюйма |
| Фон | Белый `#FFFFFF` |
| Основной текст | Тёмный `#172B4D` |
| Акцент | Синий `#2563EB` |
| Фон карточек | Светло-синий `#EFF6FF` |
| Вторичный текст | `#52657A` |
| Шрифт | Arial; проверь наличие в среде просмотра |
| Заголовки | Около 30 pt |
| Основной текст | Не менее 18 pt |
| Таблицы и ссылки | Не менее 12 pt |

Не меняй палитру, типографику, соотношение сторон и декоративный язык в
зависимости от темы. Нет тематических фонов, случайных иконок, анимаций,
градиентов и декоративных фотографий. Синий подчёркивает смысл, а не украшает
каждый элемент.

Данные представляются редактируемыми текстом, фигурами, таблицами и диаграммами
PowerPoint. Обязательные растровые изображения и импорт произвольных мастер-
шаблонов не входят в первую версию. Если они необходимы для смысла, сообщи
об ограничении и согласуй расширение; не заменяй их произвольной картинкой.

## Библиотека композиций

| layout | Назначение | Ограничение |
|---|---|---|
| `cover` | Тема, подзаголовок, выступающий | Короткие формулировки |
| `bullets` | Одна мысль и поддерживающие тезисы | До 5 пунктов |
| `comparison` | Сопоставление двух вариантов | До 4 пунктов в каждой колонке |
| `metrics` | Главные показатели | До 3 карточек; значение, подпись, контекст |
| `table` | Сопоставимые табличные данные | До 5 колонок и 6 строк данных |
| `chart` | Сравнение числовых значений | Столбчатая диаграмма, до 6 категорий и 3 рядов |
| `closing` | Итог и действия | Один вывод и до 3 действий |

Это максимумы компоновки, а не целевое наполнение. Генератор дополнительно
ограничивает длины полей и расчётное число строк. При отклонении входных
данных исправь содержание; не отключай проверку и не уменьшай шрифт.
Длинные URL не выводи на экран — используй короткие Source ID и реестр.

Показывай единицы измерения, период и контекст данных; подпись «рост» без
базы сравнения недостаточна. Ноль, отсутствие данных и «не применимо» —
разные состояния; не превращай неизвестное значение в ноль.
Не используй трёхмерные диаграммы и визуально искажающие масштабы.

Визуальная проверка включает переносы кириллицы, подписи графика, легенду,
заголовки таблиц, нижние ссылки и контраст. Не полагайся только на расчёт
длины строки: PowerPoint может использовать другой шрифт при подстановке.

Для просмотра этих композиций запусти `template --theme light-business`.
Условные данные предназначены только для просмотра шаблона и не должны
попадать в реальную презентацию как факты.
