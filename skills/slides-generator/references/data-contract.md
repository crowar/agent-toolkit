# Контракт генератора

Все JSON-файлы имеют кодировку UTF-8. Команды выполняются Python из локального
виртуального окружения. Пути ниже указаны относительно корня проекта;
при установленном через Skills CLI навыке замени `skills/slides-generator`
на фактический путь установки. Пути входных и выходных файлов относятся
к рабочему проекту пользователя, не к каталогу установленного навыка.

## outline.json

```json
{
  "version": 1,
  "title": "Название презентации",
  "mode": "research",
  "language": "ru",
  "audience": "Описание аудитории",
  "duration_minutes": 10,
  "slides": [
    {
      "id": "s01",
      "title": "Согласованный заголовок",
      "summary": "Что должен понять слушатель. На чём будет основана мысль и зачем она нужна.",
      "layout": "bullets",
      "seconds": 60
    }
  ]
}
```

`mode`: `research`, `proposal`, `report`. `version` — положительное целое.
`seconds` — положительное число секунд на слайд; суммарное время не должно
превышать `duration_minutes * 60`. В `duration_minutes` передавай доступное
время доклада без вопросов. Каждый `id` уникален и остаётся стабильным
между согласованиями одного и того же слайда.

Технические пределы первой версии: до 100 слайдов, до 360 минут, до 500
источников, до 12 ссылок на слайд (при условии, что они помещаются в нижнюю
строку). Это пределы генератора, а не рекомендуемый объём презентации.
Идентификаторы — от 1 до 32 ASCII-символов: первая буква, затем буквы,
цифры, `_` или `-`. Название презентации — до 255 символов.
Незнакомые поля JSON отклоняются, кроме дополнительных метаданных согласования.

Краткое описание проверяет агент: генератор не анализирует, действительно
ли оно состоит из 2–3 содержательных предложений.

## approval.json

Создавать **только после настоящего явного одобрения пользователем**.

```json
{
  "status": "approved",
  "outline_version": 1,
  "outline_sha256": "<SHA256 точных байтов согласованного outline.json>",
  "user_confirmation": "<фактический ответ пользователя с одобрением>"
}
```

Получение контрольной суммы:

```bash
.venv/bin/python skills/slides-generator/scripts/render_deck.py outline-hash \
  --outline output/outline.json
```

После одобрения не форматируй и не пересохраняй `outline.json`: даже замена
пробелов меняет его контрольную сумму. Если файл изменён, предъяви текущую
версию и зафиксируй новое согласование. Самостоятельное обновление хеша
в старом согласовании запрещено.

Проверка хеша защищает от случайного рассогласования, но не является
аутентификацией человека. Статус `approved` нельзя проставлять как техническую
формальность для успешного запуска команды.

## content.json

```json
{
  "slides": [
    {
      "id": "s01",
      "title": "Согласованный заголовок",
      "layout": "bullets",
      "body": {
        "items": ["Краткий тезис, проверенный по источнику"]
      },
      "speech": "Полный текст выступления на этом слайде.",
      "transition": "",
      "source_ids": ["src01"]
    }
  ],
  "sources": [
    {
      "id": "src01",
      "title": "Название исходного документа",
      "publisher": "Автор или организация",
      "date": "2026-01-15",
      "location": "materials/report.pdf",
      "locator": "Раздел 2, страница 7",
      "access": "local",
      "accessed_at": "2026-09-06"
    }
  ]
}
```

Эта иллюстрация описывает формат, а не источник фактов. Не копируй её
подстановочные значения в содержательную презентацию.

Число слайдов, порядок, `id`, `title`, `layout` точно совпадают с оглавлением.
Речь обязательна для каждого слайда. `transition` может быть пустым на
последнем слайде. `source_ids` содержит только существующие идентификаторы;
пустой список допустим на слайде без внешних фактических утверждений.
Уникальность источников и соответствие ссылок проверяет генератор, а
достоверность, полноту ссылок и смысловое соответствие — агент.

`access`: `public`, `local`, `notebooklm`, `restricted`.
`date`: дата публикации `YYYY-MM-DD` либо `n.d.`, когда она неизвестна.
`accessed_at`: фактическая дата обращения `YYYY-MM-DD`.
`location`: постоянный URL, безопасный относительный путь или идентификатор
блокнота/источника. `locator`: страница, раздел или идентифицируемый фрагмент.
Не подставляй текущую дату вместо неизвестной даты публикации.

## body для каждой композиции

```json
{
  "cover": {
    "subtitle": "Подзаголовок",
    "presenter": "Имя, роль, дата"
  },
  "bullets": {
    "items": ["Первый тезис", "Второй тезис"]
  },
  "comparison": {
    "left_title": "Вариант A",
    "left_items": ["Критерий и значение"],
    "right_title": "Вариант B",
    "right_items": ["Тот же критерий и значение"]
  },
  "metrics": {
    "items": [
      {"value": "12%", "label": "Показатель", "context": "Период и база сравнения"}
    ]
  },
  "table": {
    "columns": ["Критерий", "Значение"],
    "rows": [["Название", "Текстовое значение"]]
  },
  "chart": {
    "categories": ["Категория A", "Категория B"],
    "series": [{"name": "Ряд", "values": [10, 20]}],
    "unit": "Условные единицы; демонстрационные данные"
  },
  "closing": {
    "takeaway": "Основной вывод",
    "actions": ["Следующее действие"]
  }
}
```

В реальном слайде `body` содержит только объект выбранной композиции,
без обёртки с названием layout. Строки таблицы имеют столько же ячеек, сколько
заголовков. Все ячейки — строки. Каждый числовой ряд диаграммы имеет столько
значений, сколько категорий. Значения конечны и числовые: `NaN`, `Infinity`,
булевы значения и отсутствующие данные недопустимы.

Диапазон ненулевых значений диаграммы по модулю — от `1e-9` до `1e9`;
ноль и отрицательные значения поддерживаются. Крупные величины представляй,
например, в миллионах или миллиардах с явным указанием единицы и сохранением
исходных данных/пересчёта в исследовании. Не обрезай значения до границы
диапазона. Числа в карточках `metrics` являются строками, например `"1,2 млрд"`.

## Сборка

```bash
.venv/bin/python skills/slides-generator/scripts/render_deck.py render \
  --outline output/outline.json \
  --approval output/approval.json \
  --content output/content.json \
  --output-dir output/final
```

Выход: `presentation.pptx`, `speech.md`, `sources.md`.
Речь и переходы в заметках и отдельном файле должны совпадать.
Перед существующими файлами генератор останавливается; явный `--overwrite`
разрешает перезапись его выходных файлов.

Для пустого демонстрационного шаблона (не реальной презентации):

```bash
.venv/bin/python skills/slides-generator/scripts/render_deck.py template \
  --output-dir preview
```

Выход: `template.pptx`, `template-speech.md`, `template-sources.md`.
Режим шаблона использует только встроенные образцы, не произвольный
`content.json` в обход согласования.
